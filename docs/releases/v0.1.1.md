修复终端：会话不再无故断开，粘贴大段文字也不再卡。

## 修好了什么

- **终端会话不再断开**：以前通过 Nginx、EdgeOne 这类代理访问 Web 版时，终端一段时间没有输出，连接就会被代理掐断，页面随后显示「会话已结束」。现在：
  - 连接断了会自动重连，并从断开的地方接着显示，中间的输出一个字都不丢；
  - 服务器上的 shell 在没人连着时保留 10 分钟（以前 2 分钟），切到别的页面再回来还是原来那个会话；
  - 到服务器的 SSH 连接每 30 秒检查一次，网络真的断了能很快发现；
  - 断网、电脑休眠后回来，会马上重新连接。
- **粘贴不再慢**：输出不再被代理攒着一起发，粘贴一大段命令或配置时立刻就能看到。

## 下载哪个文件

| 系统 | 文件 |
|---|---|
| Windows | `MiaoPanel-windows-amd64.exe`（ARM 电脑用 `MiaoPanel-windows-arm64.exe`） |
| Linux 服务器（Web 版） | `MiaoPanel-linux-amd64` / `MiaoPanel-linux-arm64` |
| macOS | `MiaoPanel-darwin-arm64` / `MiaoPanel-darwin-amd64` |

Web 版替换同名文件后重启服务即可，数据和设置都会保留。部署和升级步骤见[部署文档](https://github.com/bocmiao/CloudConsoleWithAI/blob/HEAD/docs/DEPLOY.md)，`SHA256SUMS.txt` 是各文件的校验值。
