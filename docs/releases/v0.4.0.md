Web 版不再需要 Docker：下载安装包、运行一个脚本，在浏览器里按安装向导选好数据库、建好管理员账号就能用。数据可以放在内置数据库，也可以放在已有的 MySQL / MariaDB。

## 新功能

- **Linux 安装包**：发布里新增 `MiaoPanel-linux-amd64.tar.gz`（ARM 服务器用 `-arm64`）。解压后运行 `sudo sh install.sh`：
  - 装成开机自启的 systemd 服务，以专用的 `miaopanel` 用户运行，程序和数据都在 `/opt/miaopanel`；
  - 默认监听 18765 端口，浏览器直接打开 `http://服务器IP:18765`；服务器上开着 ufw 或 firewalld 时自动放行（云服务器的安全组还要在控制台放行）；
  - 最后显示访问地址和初始化码；
  - 用安装包装的也能在「设置 → 版本和诊断」一键更新；
  - 再运行一次就是升级，端口和数据都保留；`--port` 换端口，`--local` 只让本机的反向代理访问；
  - 之前手动配置过 systemd 的，运行它就会接管，继续用原来的数据；
  - `sudo sh /opt/miaopanel/uninstall.sh` 卸载，默认保留数据，加 `--purge` 连数据一起删除。
- **安装向导**：第一次打开 Web 版时分三步：
  1. 输入初始化码：只有能登录这台服务器的人才看得到，别人抢不走安装；
  2. 选择数据库：内置数据库（什么都不用准备），或者 MySQL；
  3. 创建管理员账号。
- **MySQL / MariaDB**：支持 MySQL 5.7+ 和 MariaDB 10.3+。
  - 填好地址、端口、库名和账号后可以先「测试连接」；库还不存在、账号又有建库权限时自动创建；
  - 连到 Miao Panel 用过的库时，直接用原来的账号登录；
  - 服务器密码、云服务密钥这些仍然只保存在服务器的数据目录里，不写进 MySQL。

## 其他改进

- 用 Go 1.26.8 编译，包含 Go 1.26.0 之后的标准库安全修复。
- 「设置」的「安全」一栏显示数据保存在哪里。
- Docker 版的新数据卷同样先出现安装向导；已有数据的不受影响。

## 下载哪个文件

| 系统 | 文件 |
|---|---|
| Windows | `MiaoPanel-windows-amd64.exe`（ARM 电脑用 `MiaoPanel-windows-arm64.exe`） |
| Linux 服务器（Web 版，推荐） | 安装包 `MiaoPanel-linux-amd64.tar.gz` / `MiaoPanel-linux-arm64.tar.gz` |
| Linux 服务器（只要程序文件） | `MiaoPanel-linux-amd64` / `MiaoPanel-linux-arm64` |
| macOS | `MiaoPanel-darwin-arm64` / `MiaoPanel-darwin-amd64` |

从 v0.3.0 升级：在「设置 → 版本和诊断」点「更新到 v0.4.0」即可，数据和设置都会保留，已经在用的不会看到安装向导。
Docker 版在项目目录运行 `git pull && docker compose up -d --build`；手动配置的 systemd 版可以直接运行新安装包里的 `install.sh` 接管。
部署和升级步骤见[部署文档](https://github.com/bocmiao/CloudConsoleWithAI/blob/HEAD/docs/DEPLOY.md)，`SHA256SUMS.txt` 是各文件的校验值。
