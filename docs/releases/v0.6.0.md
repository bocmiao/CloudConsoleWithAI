云控制台里常做的几件事也搬进来了：服务器一键回滚到快照、腾讯云和阿里云的 CDN 放在一个页面管理、申请免费证书、云监控告警、EdgeOne 的限速和 CC 防护。每一项都先生成清单、确认后执行，AI 也都能用。

## 新功能

- **快照回滚**：「云服务器」详情的快照列表里点「回滚到这里」。
  - 生成的清单第一步先给现在的系统盘做一个快照，想反悔可以再回滚到它；
  - 服务器开着的会先正常关机，回滚完自动开机；
  - 腾讯云（轻量和 CVM）、阿里云（ECS 和轻量）都支持；
  - 回滚会丢掉快照之后写入的数据，页面和清单里都会说清楚。
- **CDN 页**：侧边栏「云服务」下新增「CDN」，腾讯云 CDN 和阿里云 CDN 的加速域名在一起：
  - 状态、CNAME、源站、HTTPS 和证书到期时间；
  - 刷新缓存（网址或整个目录，只写路径也行）、预热、启用或停用；
  - 腾讯云 CDN 可以选一张 SSL 证书开启 HTTPS，或者直接申请免费证书，签发后自动配置上。
- **免费证书**：「证书」页新增「腾讯云免费证书」。
  - TrustAsia 免费证书，有效期 3 个月；
  - 域名的解析在这个账号的 DNSPod 里时自动验证，一般几分钟签发；
  - 签发后可以用在腾讯云 CDN、负载均衡等产品上。
- **云监控告警**：「监控」页下面列出腾讯云和阿里云云监控最近 7 天的告警。
  - 没恢复的排在前面，点一条让 AI 查原因；
  - 总览的「需要你处理」和提醒推送也会说（通知里的「云监控告警」，默认开）。
- **EdgeOne 防护**：「EdgeOne」页新增「防护」：
  - 列出站点的速率限制规则，可以添加（比如登录页同一个 IP 每分钟超过 60 次就挑战）和删除；
  - 开关 CC 防护（自适应频控），选灵敏度和处理方式；
  - 启用或停用加速域名；
  - 都能撤销。
- **AI**：能查 CDN 加速域名和云监控告警，能提出回滚、CDN 刷新预热启停、开启 HTTPS、申请免费证书的清单。

## 需要的权限

- **腾讯云**：
  - CDN 页要给子账号加 `QcloudCDNFullAccess`；
  - 申请免费证书要 `QcloudSSLFullAccess`（原来的 `QcloudSSLReadOnlyAccess` 只能查看）；
  - 回滚用原来的服务器和快照权限；
  - 告警用原来的 `QcloudMonitorReadOnlyAccess`。
- **阿里云**：回滚、CDN 启停、告警用原来的权限，不需要新加。
- 腾讯云 CDN 的 HTTPS 请求按量计费。

## 下载哪个文件

| 系统 | 文件 |
|---|---|
| Windows | `MiaoPanel-windows-amd64.exe`（ARM 电脑用 `MiaoPanel-windows-arm64.exe`） |
| Linux 服务器（Web 版，推荐） | 安装包 `MiaoPanel-linux-amd64.tar.gz` / `MiaoPanel-linux-arm64.tar.gz` |
| Linux 服务器（只要程序文件） | `MiaoPanel-linux-amd64` / `MiaoPanel-linux-arm64` |
| macOS | `MiaoPanel-darwin-arm64` / `MiaoPanel-darwin-amd64` |

从 v0.5.0 升级：在「设置 → 版本和诊断」点「更新到最新版本」即可，数据和设置都会保留。
部署和升级步骤见[部署文档](https://github.com/bocmiao/CloudConsoleWithAI/blob/HEAD/docs/DEPLOY.md)，`SHA256SUMS.txt` 是各文件的校验值。
