喵面板的第一个正式版本：一个开源的 AI 服务器与云管理助手。用大白话说想干什么，它先登录服务器、查腾讯云把情况查清楚，再给你一份写明风险、能一键执行、能撤销的清单，你点头它才动手。

## 下载哪个文件

| 系统 | 文件 | 怎么用 |
|---|---|---|
| Windows（大多数电脑） | `MiaoPanel-windows-amd64.exe` | 双击运行，打开自己的窗口 |
| Windows（ARM 电脑） | `MiaoPanel-windows-arm64.exe` | 同上 |
| Linux 服务器（Web 版） | `MiaoPanel-linux-amd64`，ARM 服务器用 `MiaoPanel-linux-arm64` | 用 systemd 运行 `miaopanel serve`，见[部署文档](https://github.com/bocmiao/CloudConsoleWithAI/blob/HEAD/docs/DEPLOY.md) |
| macOS（Apple 芯片 / Intel） | `MiaoPanel-darwin-arm64` / `MiaoPanel-darwin-amd64` | 在终端运行，在浏览器里打开 |

也可以用 Docker 部署 Web 版：`git clone` 仓库后 `docker compose up -d --build`，步骤见[部署文档](https://github.com/bocmiao/CloudConsoleWithAI/blob/HEAD/docs/DEPLOY.md)。`SHA256SUMS.txt` 是各文件的校验值。

## 能做什么

- **AI 助手**：先查服务器和腾讯云，再给出可以勾选执行的清单；执行前检查、备份，失败自动恢复，做完能撤销；
- **服务器**：1Panel、宝塔、纯 Linux 都能用；swap、日志清理、重启服务和容器，1Panel 上新建网站、调 PHP-FPM 和 MySQL、限制应用内存、备份；
- **腾讯云**：一句话上线网站（EdgeOne + 1Panel + DNSPod + 免费证书）；EdgeOne 实时数据、封禁、限速、CC 防护；轻量和 CVM 的端口、快照、开关机；
- **网站统计和安全**：PV、UV、IP、流量、爬虫、死链；给 IP 打分，一键或自动封禁；
- **解析**、**存储（COS）**、**证书**、**文件管理**、**终端**、**日报和提醒**（企业微信、钉钉、飞书、Server酱）；
- **Web 版**：密码 + 两步验证，可选邮箱、短信（腾讯云或阿里云）验证码登录，默认只给管理员的邮箱和手机号发送；手机浏览器也好用。

## 第一次使用

1. 在「设置」里选一个 AI 模型（推荐 DeepSeek V4.1 Flash），填 API Key；
2. 添加服务器（IP、用户名、密码或私钥），点「识别环境」；
3. 到「AI 助手」里用大白话提问。

没点「执行」之前只会**查看**服务器，不会做任何修改。

## 注意

- 程序没有代码签名。Windows 可能提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」；macOS 下载后先在终端运行 `chmod +x MiaoPanel-darwin-arm64 && xattr -d com.apple.quarantine MiaoPanel-darwin-arm64`；
- Web 版保存着你所有服务器的密钥，请只通过 HTTPS 访问，并开启两步验证；
- 腾讯云请用只给了必要权限的子账号，设置页里有步骤。
