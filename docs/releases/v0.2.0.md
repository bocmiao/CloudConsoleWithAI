新增网站管理和 EdgeOne 缓存清除、预热；界面重新设计，打开先看到总览，AI 在任何页面都能问。

## 新功能

- **网站管理**：侧边栏「网站 → 网站管理」列出每台服务器 1Panel 上的网站，能看到类型、运行状态和证书还剩几天。打开一个网站可以：
  - 启动、停止网站，添加、删除域名；
  - 设置 HTTPS：选证书、HTTP 自动跳转到 HTTPS、HSTS、HTTP/3，也能直接申请免费证书；
  - 添加、修改、停用反向代理规则；
  - 改伪静态规则（可以从 WordPress 等模板开始），直接改网站的 Nginx 配置文件；
  - 看访问日志和错误日志（默认最后 200 行，最多 2000 行）；
  - 删除网站（删除前先用 1Panel 备份）。

  每次修改都先生成清单，你确认后才执行，执行后可以撤销（删除网站除外）。改配置文件和伪静态时，清单里会列出改了哪几行；1Panel 会先用 `nginx -t` 检查，配置有错就保留原来的文件，网站不受影响。别人在这期间改过这个文件的话，不会被覆盖。AI 也会用这些操作，比如「给 blog 加一个 /api 的反向代理到 9000 端口」。
- **EdgeOne 缓存清除和预热**：在网站详情的「EdgeOne 缓存」和 EdgeOne 页的「清除 / 预热缓存」里，填路径就行（如 `/css/app.css`），可以清除网址、目录、整个域名或整个站点，也可以把新文件提前预热到节点。
- **搜索和跳转**：按 Ctrl+K（Mac 上 ⌘K）或点侧边栏的「搜索」，能搜服务器、网站和页面；输入「终端 blog」「文件 blog」直接打开那台服务器的终端或文件；搜不到的话可以直接交给 AI。

## 界面重新设计

- **总览**成为首页：服务器、网站、证书、安全各一张卡片，下面是需要你处理的事（没封禁的高风险 IP、快到期的证书、等你确认的清单、服务器的问题）、今天的访问和最近的变更，每一条都能一键跳过去或交给 AI。
- **侧边栏分组**：服务器（前面的小圆点表示状态）、网站（网站管理、访问统计、安全、证书）、腾讯云（EdgeOne、解析、存储）。
- **AI 侧栏**：任何页面按 Ctrl+J / ⌘J 或点「问 AI」打开，和 AI 助手页是同一个对话，AI 知道你正在看哪个页面、哪个网站。窗口够宽时页面会让出位置。
- **颜色更简单**：只保留一个蓝色做主色，绿、橙、红只用来标状态；新的猫耳 M 图标。

几个入口换了位置：原来的「建议」和「通知」合并成「待处理」，「日志」改名「记录」，「网站统计」分成「访问统计」「安全」和「EdgeOne」三项。

## 其他改进

- 总览里的证书数量和证书页一致。
- 过滤栏里的文字标签不再上下错开。

## 下载哪个文件

| 系统 | 文件 |
|---|---|
| Windows | `MiaoPanel-windows-amd64.exe`（ARM 电脑用 `MiaoPanel-windows-arm64.exe`） |
| Linux 服务器（Web 版） | `MiaoPanel-linux-amd64` / `MiaoPanel-linux-arm64` |
| macOS | `MiaoPanel-darwin-arm64` / `MiaoPanel-darwin-amd64` |

从 v0.1.x 升级直接替换文件即可，数据和设置都会保留；Web 版替换同名文件后重启服务。网站管理用的是已经设置好的 1Panel 接口，还没设置的服务器在网站页会提示怎么设置。部署和升级步骤见[部署文档](https://github.com/bocmiao/CloudConsoleWithAI/blob/HEAD/docs/DEPLOY.md)，`SHA256SUMS.txt` 是各文件的校验值。
