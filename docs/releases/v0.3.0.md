支持宝塔面板和阿里云；新增监控告警、网站备份和恢复、服务器工作台；以后可以在设置里检查更新、一键更新。

## 新功能

- **监控和告警**：侧边栏「监控」每分钟打开一次你的每个网站（1Panel 和宝塔上运行中的网站、其他服务器 Nginx 配置里的域名，也可以手动添加），每两分钟看一次服务器的 CPU、内存、磁盘和网络，保存 7 天。网站连续两次打不开、服务器连不上、磁盘快满、内存或 CPU 长时间过高，会提醒到「待处理」，也能推送到企业微信、钉钉、飞书、Server酱或邮件；恢复了再说一声。
- **网站备份和恢复**（1Panel）：网站详情里的「备份」可以立即备份（带备注）、设置每天自动备份（由 1Panel 的计划任务在服务器上跑，保留几份、放在本机还是 COS 等备份账号）、下载备份，或者一键恢复到某一份——恢复前先把现在的网站备份一份。
- **宝塔面板**：在服务器的「连接设置」里填好宝塔的接口密钥，宝塔上的网站就和 1Panel 的一起出现在「网站管理」：启停、域名、HTTP 跳转 HTTPS、申请免费证书、反向代理、伪静态、Nginx 配置文件、日志和立即备份，同样先出清单、能撤销。
- **阿里云**：在「设置 → 阿里云」填一个 RAM 用户的 AccessKey（页面上有创建步骤和要勾的权限）：
  - ECS 和轻量应用服务器出现在「云服务 › 云服务器」，和腾讯云的在一起：到期、流量包、24 小时监控、防火墙（安全组）和快照，开机、关机、重启、创建快照、放行或关闭端口；
  - 阿里云云解析的域名出现在「解析」页，添加、修改、暂停、删除记录，一键解析到服务器、IP 或域名；
  - AI 能刷新和预热阿里云 CDN 缓存。
- **服务器工作台**：点侧边栏的服务器，分成「概览 · 网站 · 应用 · 安全与备份 · 执行记录 · 连接设置」。概览里是 CPU、内存、磁盘、流量包的圆环和最近 24 小时的曲线，体检发现的问题旁边就是处理按钮。
  - **应用**：每个容器和系统服务都能重启；1Panel 服务器上还能看、新建、备份和删除 MySQL 数据库（新建时密码随机生成，Miao Panel 不保存）。
  - **安全与备份**：一份清单先在 1Panel 备份数据库和应用，再创建腾讯云整盘快照；收紧安全组；SSH 登录加固（带 5 分钟自动恢复保险）。
- **腾讯云 › 云服务器**页：轻量和 CVM 的到期、流量包、监控、防火墙和快照，开关机、重启都在这里。
- **检查更新和一键更新**：「设置 → 版本和诊断」每天问一次 GitHub 有没有新版本（只请求版本号，不发送任何数据，可以关掉），有新版本时总览会提醒。从这个版本以后，点「更新到 vX」就会下载新程序、核对 `SHA256SUMS.txt` 后替换并自动重启。Docker 版和 systemd 版仍按部署文档更新。
- **诊断包**：遇到问题时「下载诊断包」附在反馈里：版本、系统、哪些功能配置了、最近的操作记录和故障，没有密钥、密码和对话内容，服务器地址只保留前两段。

## 其他改进

- 程序更小：加了宝塔、阿里云等功能，Windows 版反而从 33.8 MB 降到 31.4 MB（内置的 IP 归属地数据库改用 xz 压缩）；网页脚本和样式压缩后发送，Web 版首次打开要下载的内容从约 1.3 MB 降到约 360 KB，再次打开只确认有没有变化。
- 边生成边显示 AI 回答时，可以往上翻看前面的内容，不会被拉回底部。
- Web 版更严格地识别反向代理带来的访客 IP；AI 接口地址只有指向本机（localhost、127.0.0.1）时才允许用 http。
- 自动封禁的到期解封记录保存失败时会提醒你手动检查 EdgeOne 的封禁规则；对话记录保存失败时会提示，回答不会丢。

## 下载哪个文件

| 系统 | 文件 |
|---|---|
| Windows | `MiaoPanel-windows-amd64.exe`（ARM 电脑用 `MiaoPanel-windows-arm64.exe`） |
| Linux 服务器（Web 版） | `MiaoPanel-linux-amd64` / `MiaoPanel-linux-arm64` |
| macOS | `MiaoPanel-darwin-arm64` / `MiaoPanel-darwin-amd64` |

从 v0.2.x 升级直接替换文件即可，数据和设置都会保留；Web 版替换同名文件后重启服务，Docker 版在项目目录运行 `git pull && docker compose up -d --build`。宝塔和阿里云需要先在设置里填好接口密钥。部署和升级步骤见[部署文档](https://github.com/bocmiao/CloudConsoleWithAI/blob/HEAD/docs/DEPLOY.md)，`SHA256SUMS.txt` 是各文件的校验值。
