# Miao Panel（喵面板）

一个**开源、通用**的 AI 服务器与云管理助手，支持 1Panel、宝塔和纯 Linux。任何 Linux 服务器都能用：装了 1Panel、宝塔，或者什么面板都没装；云产品先支持腾讯云（EdgeOne、DNSPod、轻量、CVM）。先做成 Windows 本地 exe，之后做 Web 版。

- **一句话建站**：「把 blog.example.com 上线到我的服务器，走 EO，开 HTTPS」→ 自动完成 EO 站点、加速域名、DNSPod 解析、防火墙、证书和面板建站，并验证结果。
- **访问统计**：「今天下午流量为什么涨了？」→ 基于 EO 数据分析自动归因（Top IP / URL / UA / 地区）。
- **服务器状态**：CPU、内存、磁盘、带宽、到期时间一屏总览；「现在是什么在吃内存？」直接问。
- **AI 排障**：「网站打不开」→ 按 DNS → EO → 网络 → 主机 → 应用逐层取证，给出结论、证据和修复方案。
- **优化建议，同意后自动执行**：先用数据判断是否真有问题，再给出具体改法；你同意后自动执行，失败自动回滚，事后汇报效果。1Panel、宝塔上的修改走面板自己的 API，面板里看得到、不会被覆盖。
- **看不懂命令也能安全使用**：AI 只能提交计划；模板覆盖不到时可以开启受限的 AI 自由命令，由系统替你检查命令、试运行、做快照，并设置「5 分钟保险」自动恢复。

完整设计见 [docs/DESIGN.md](docs/DESIGN.md)。

## 怎么用（Windows）

1. 在仓库的 Actions 或 Releases 页面下载 `MiaoPanel-windows-amd64.exe`；
2. 双击运行，会打开 Miao Panel 自己的窗口（用的是 Windows 自带的 WebView2，和很多桌面软件一样；没有黑色命令行窗口，关掉窗口就是退出）。再次双击只会把已经打开的窗口切到前面；
3. 按页面上的三步走：**设置 AI 模型**（推荐 DeepSeek V4.1 Flash，在 DeepSeek 开放平台创建 API Key）→ **添加服务器**（IP、用户名、密码）→ **识别环境**；
4. 到「AI 助手」里用大白话说你想干什么，比如「服务器内存是不是太高了？帮我优化一下」；
5. AI 检查完会给出一份**清单**，勾选想做的项目，点「执行」并确认，就会自动完成，并显示执行前后的对比；能撤销的项目可以一键撤销。

没点「执行」之前，程序只**查看**服务器，不做任何修改；清单也保存在「建议」页。目前能自动执行的操作：添加 swap、清理旧日志、重启服务、重启容器，以及 1Panel 上的新建网站、调整 PHP-FPM 进程数、调整 MySQL 内存参数、设置应用内存上限、固定 Java 应用的最大堆、备份应用或数据库；腾讯云上的操作见下面。详见 [设计文档第 18 节](docs/DESIGN.md)。

**腾讯云**：在「设置 → 腾讯云」填入一个子账号的 SecretId 和 SecretKey（页面上有创建步骤和要勾选的权限，不要用主账号；用自动化助手连接服务器还要 QcloudTATFullAccess，在「证书」页看腾讯云 SSL 证书要 QcloudSSLReadOnlyAccess）。之后在 AI 助手里可以：

- **上线网站**：「把 blog.example.com 上线到我的服务器，走 EO，开 HTTPS」→ 清单：新建 EdgeOne 站点（需要时，自动完成域名验证）→ 在 1Panel 里建站（反向代理到应用）→ 添加 EdgeOne 加速域名 → DNSPod 解析切到 EdgeOne → 申请免费证书。新建站点要绑定账号里已有的 EdgeOne 套餐，购买套餐涉及计费，需要你自己在控制台操作；
- **管理服务器**（轻量应用服务器和 CVM）：查看所有地域的实例、到期时间、流量包、防火墙、快照和最近的 CPU/内存/带宽；放行或关闭端口（22、3389 不允许关）、创建快照、开机、关机、重启。添加服务器时可以直接「从腾讯云选择」；
- **分析网站访问**：「网站统计 → EdgeOne 实时」显示 EdgeOne 的请求数、流量、带宽、缓存命中率、响应时间（和前一段时间对比）以及网址、国家/地区、状态码、IP、来源、设备、浏览器、各域名的排行；「访问分析」用 EdgeOne 离线日志统计 PV、UV、IP 和风险 IP（见下面）。点「让 AI 分析」或直接问「今天下午流量为什么涨了？」，AI 会按时段和各个维度查数据找原因，并给出建议；
- **管理 EdgeOne**：清除或预热缓存、启用或停用加速域名、修改回源地址；
- **防护**：AI 在访问数据里发现刷量或攻击时，可以封禁 IP、给登录页等路径按 IP 限速、开启 CC 防护（自适应频控），都能一键回滚；
- **不用密码连接服务器**：添加服务器时「从腾讯云选择」，登录方式选「自动化助手」（腾讯云 TAT），不需要 SSH 密码，也不用开放 SSH 端口。

每一步都写进执行日志，能回滚的可以一键回滚；只涉及腾讯云的清单不需要连服务器。

**证书**：侧边栏「证书」页汇总 EdgeOne、腾讯云 SSL 证书和各台服务器 1Panel 里的 HTTPS 证书，并实际访问每个网站确认，快到期、已过期、没开自动续签或者续签失败的会标出来；可以只看需要处理的或不会自动续签的，搜索域名或服务器，按紧急程度、到期时间或域名排序。申请证书交给会一直在线的一方自动续签：经过 EdgeOne 的网站用 EdgeOne 免费证书；1Panel 服务器让 1Panel 向 Let's Encrypt 申请（HTTP 验证，泛域名用 DNS 验证），开启自动续签并给网站开启 HTTPS。都能一键回滚。

**AI 自由命令**（默认关闭，在「设置 → AI 自由命令」开启）：没有现成模板时，AI 可以现场写命令，比如给 Nginx 开 gzip、改某个软件的配置。你看到的不是命令，而是「会改哪些文件（修改前后对比）、会重新加载哪些服务、通过了哪些检查」。系统会先解析命令（只允许改服务配置、重载服务这类操作，SSH、账号、防火墙、面板管理的文件都不能碰），在服务器上隔离试运行，再请另一个 AI 独立审查；执行前自动备份，失败立即恢复，还有「5 分钟保险」：执行后 Miao Panel 连不上服务器，服务器会自己恢复原状。能大幅降低风险，但做不到零风险。

**网站访问统计**：「网站统计 → 访问分析」按请求日志统计每个网站（或全部网站）今天、7 天、30 天的 PV、UV、独立 IP、请求、爬虫、流量和错误，分成四块：

- **概览**：需要处理的问题（敏感文件被下载、没封禁的高风险 IP、服务器出错多）、关键数字（和前一段时间对比）、每天或每小时的走势、热门页面、来源、地区和各网站；
- **访客**：地区（省份/国家）、来源、访客 IP（点开看它的地区、运营商、访问时间、看了什么、每分钟最多几次）、运营商、设备、爬虫和程序；
- **内容**：受访页面、访问目录、出错的地址、死链（有人点链接打开却是 404，并指出链接在哪个页面或网站上）、状态码；
- **安全**：按规则给每个 IP 打分（探测后台和密钥文件、请求带攻击代码、猜密码、异常高频、冒充搜索引擎……），可以让 AI 研判后勾选「封禁」，生成清单确认后在 EdgeOne 拦截，也能一键解封。EdgeOne 节点、内网地址和已验证的搜索引擎爬虫（反查域名确认）不会被封。也可以开启**自动封禁**：每次统计更新（每 20 分钟）按规则封禁高风险 IP（可以要求 AI 也同意），封 1 小时到 30 天或一直封，到期自动解封，解封后又来的会再封；每次封禁和解封都生成清单，能撤销，还可以列出永远不封的 IP。

数据有两个来源：经过 EdgeOne 的网站用 **EdgeOne 离线日志**（每个请求都有、访客 IP 真实，最准，有十几分钟到一小时延迟；下载过的日志包留在本地不重复下载）；也可以统计**服务器上的访问日志**（1Panel、宝塔或 Nginx，实时；日志只在服务器上统计，只把汇总结果传回来）。IP 所在地（IPv4 和 IPv6）用离线的 [ip2region](https://github.com/lionsoul2014/ip2region) 数据库查询，不联网。所有数据在启动时和之后每 20 分钟在后台更新，打开页面、切换时间范围都是立即显示。也可以直接问 AI「我的网站这周访问量怎么样」「有没有人在扫描我的网站」。

**日报和提醒**：侧边栏「通知」每天生成一份访问日报（前一天的 PV、UV、IP 和比前一天、比上周同一天的变化，各网站、热门页面、地区，高风险 IP、死链、证书情况），并在发现新的高风险 IP、敏感文件被下载、证书快到期或出问题、自动封禁做了什么时提醒，同一件事不重复提醒。都保存在「通知」页，也可以推送到企业微信、钉钉、飞书群机器人（支持加签），Server酱（推送到微信），或者任意 Webhook。

**终端**：侧边栏「终端」（或服务器页的「终端」按钮）打开服务器的命令行（SSH），可以开多个标签页；切换页面、刷新页面都不会断开。终端里敲的命令直接在服务器上执行，不经过 AI 检查，也不会自动备份，只在日志里记录打开和关闭。用腾讯云自动化助手连接的服务器没有 SSH，不能打开终端。

**文件**：侧边栏「文件」（或服务器页的「文件」按钮）像电脑上的文件管理器一样管理服务器上的文件（通过 SSH 的 SFTP）：浏览、上传（可以把文件拖进来，显示进度）、下载（文件夹会打包成 .tar.gz）、新建文件和文件夹、直接编辑文本文件（Ctrl+S 保存；别人同时改过会提醒，不会悄悄覆盖）、复制 / 剪切 / 粘贴（同名时可选覆盖、都保留或跳过）、重命名、删除、压缩（tar.gz、zip）和解压（zip、tar.gz、tar.xz、7z、rar 等）、改权限和所有者（新上传和新建的文件自动跟随所在文件夹的所有者，网站不会因为文件属于 root 而读写不了）。支持右键菜单和常用快捷键（Ctrl+C / X / V、Delete、F2、Backspace 返回上一级），有 1Panel 和宝塔网站目录等常用位置。改动直接生效，不经过 AI，每一次都记在「日志」里；系统目录（如 `/etc`、`/usr`）和登录要用的文件（如 `~/.ssh/authorized_keys`）不能删除或移动。用腾讯云自动化助手连接的服务器没有 SSH，不能使用。

**实时回复**：AI 的回答边生成边显示，它正在查什么（比如「分析网站访问数据 · ui.miao.club」）也会实时列出来；回答时发送按钮变成「■ 停止」，随时可以中断，已经说出的部分会保留。

**对话记录**：和 AI 的对话会自动保存，关掉程序再打开也在，还能接着问；在 AI 助手页左侧的「对话记录」里切换或删除。

**日志和回滚**：「日志 → 执行日志」里能查到 Miao Panel 在服务器上执行过的每一条命令（包括 AI 的只读检查）和结果；改过的东西可以在这里一键回滚。能回滚的修改还会在服务器的备份目录里留一个 `rollback.sh`，就算电脑上的 Miao Panel 不在了，也能在服务器上用 root 执行它恢复。

**1Panel 用户**：在 1Panel「面板设置 → API 接口」开启 API，IP 白名单填 `127.0.0.1`，把密钥粘贴到 Miao Panel 的服务器页「1Panel 接口」里并点「测试」。这样 PHP、MySQL 的修改会走 1Panel 自己的接口，面板里看得到、不会被覆盖。

密码和 API Key 保存在 Windows 凭据管理器里。

少数没有 WebView2 运行库的旧版 Windows 10 会提示安装，并临时改用浏览器打开。想用浏览器的话，可以带参数运行：`MiaoPanel.exe --browser`。macOS 和 Linux 版目前也是在浏览器里打开。

## 从源码构建

需要 Go（版本见 `go.mod`），不需要 Node.js（界面用的是 Vue 3 浏览器版，已经放在仓库里）：

```bash
go test ./...                                                   # 运行测试
go build -o miaopanel ./cmd/miaopanel                           # 当前系统
GOOS=windows GOARCH=amd64 go build -o MiaoPanel.exe ./cmd/miaopanel  # Windows exe
```

运行参数：`--port`（默认 18765，被占用时自动换一个）、`--data`（数据目录，默认是用户配置目录下的 `MiaoPanel`）、`--browser`（Windows 上用浏览器代替独立窗口）、`--no-browser`（浏览器模式下不自动打开浏览器）。

Windows 版要加 `-H=windowsgui` 编译成窗口程序（CI 已经这样做）；程序图标、版本信息和高 DPI 声明在 `cmd/miaopanel/rsrc_windows_*.syso` 里，由 `cmd/miaopanel/winres/` 用 [go-winres](https://github.com/tc-hib/go-winres) 生成：`cd cmd/miaopanel && go-winres make --in winres/winres.json --arch amd64,arm64`。

## 服务器环境识别脚本

[`scripts/discover.sh`](scripts/discover.sh) 是一个只读脚本，用来识别服务器上跑了什么（1Panel / 宝塔、Nginx 站点、PHP-FPM、MySQL / Redis、Docker、WordPress、Java 等），输出一份脱敏后的精简报告。系统会通过 SSH 或腾讯云自动化助手（TAT）自动执行它，你也可以手动运行：

```bash
sudo bash scripts/discover.sh               # 全部段落
sudo bash scripts/discover.sh docker web    # 只看指定段落
```

也可以把脚本内容粘贴到腾讯云控制台「自动化助手 → 执行命令」里，以 Shell 类型执行。
